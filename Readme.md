# Product Inventory Monitor System By Yusuf Balla Keita

## 1. Introduction

The Product Inventory Monitor System is a Python application designed to help users manage products, categories, stock quantities, and inventory values.

The system makes it easier to record products, update stock, and calculate the financial value of available inventory.

## 2. Objectives

* To manage product information.
* To organize products into categories.
* To add to existing stock quantities.
* To calculate the total cost value of inventory.
* To calculate the expected selling value and expected profit.
* To reduce errors in manual inventory management.

## 3. Features

* Add and manage product categories.
* Register new products.
* Update the stock quantity of existing products.
* Display product information.
* Calculate inventory cost and expected selling values.
* Calculate expected profit.
* Validate user input and handle errors.

## 4. Technologies Used

* Python
* Python lists for storing product and category information.
* Python's built-in functions and modules, where required.

## 5. Data Storage

The system uses Python lists to store product and category information while the program is running.

The information is stored in the computer's memory and is not permanently saved unless file storage or a database is added.

Therefore, the information stored in the lists will normally be lost when the program closes.

## 6. Financial Calculations

The system uses the following formulas:

**Total Cost Value** = Unit Cost Price × Quantity

**Total Expected Selling Value** = Unit Selling Price × Quantity

**Expected Profit** = (Unit Selling Price − Unit Cost Price) × Quantity

Expected profit does not include other business expenses.

## 7. How to Run the Program

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or another Python editor.
4. Run the main Python file.

## 8. Limitations

* Information stored in lists is not permanently saved.
* The system does not automatically synchronize information between computers.
* Additional features may be required for large businesses.

## 9. Future Improvements

* Add permanent data storage using a file or database.
* Develop a graphical user interface.
* Add stock alerts for low inventory.
* Generate inventory reports.

## 10. Conclusion

The Product Inventory Monitor System provides a simple way to manage products, categories, stock quantities, and inventory calculations using Python.
